# physio-timer

Make this file a single, self-contained web page with zero external dependencies. It is meant for mobile use but should
also work on any screen size.

I have to do physio exercises daily. There are six sets of exercises, each lasting 30 seconds each, with a 60 second rest period between sets.

Before the timer has started the screen should be black with white text in the center of the page saying 'Tap to start'.

During a set the screen should have a green background with white text.

While the timer is in progress the page should just have the mm:ss timer in the center of the page.

During a rest the screen should be blue with white text.

When the timer has ended the screen should be black with white text and say 'Refresh to reset'.

Don't add a page title or instructions or any text anywhere.

I should be able to tap anywhere on the page to play, pause or resume.

Refreshing the page resets the timer to zero.

Finally, add an entry to the parent index.html

Before building, ask me questions to clarify.
